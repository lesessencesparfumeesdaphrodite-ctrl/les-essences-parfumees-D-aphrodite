Cartes cadeaux – mon outil

Outil privé de Zulay : il crée la carte (image + PDF), le code personnel, et prépare le fichier à déposer sur GitHub.

Comment l'utiliser

  1. Créer une carte (étape 1) quand une commande de carte cadeau arrive, puis envoyer l'image ou le PDF au client par e-mail.
  2. Cliquer sur « Télécharger cartes-cadeaux.json » (étape 2) et le déposer sur GitHub (glisser-déposer, comme pour index.html).
  3. Quand quelqu'un utilise sa carte, une commande arrive avec le code : aller à l'étape 3, déduire le montant, retélécharger le fichier et le redéposer sur GitHub.
